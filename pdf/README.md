# PDF

Fiches publiées avec le site :

| Fichier | Usage | Adresse |
|---|---|---|
| `LeRepere_Forfaits_2027.pdf` | Version écran (bouton « Télécharger la fiche des forfaits ») | https://lerepere.info/pdf/LeRepere_Forfaits_2027.pdf |
| `LeRepere_Forfaits_2027_impression.pdf` | Version impression (fond blanc) | https://lerepere.info/pdf/LeRepere_Forfaits_2027_impression.pdf |
| `LeRepere_QR_lerepere-info.png` | Code QR vers lerepere.info, utilisé dans les fiches | — |

Pour remplacer une fiche, gardez le **même nom de fichier** : le bouton du site continue de
fonctionner. Si le nom change, mettez à jour le lien dans `index.html` (les tests vérifient que le
fichier existe).

Les prix des fiches doivent rester identiques à ceux du site (voir « Changer un prix » dans le
README principal).
